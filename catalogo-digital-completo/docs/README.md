# Documentação do Catálogo Digital

- `STATUS_ATUAL.md` — ponto atual e próximo teste.
- `ROADMAP.md` — plano completo de continuidade e melhorias.
- `ARQUITETURA_TECNICA_DEFINITIVA.md` — arquitetura.
- `PLANO_RECUPERACAO_DESASTRE.md` — recuperação e backup.
- `historico/fases/` — documentação técnica das fases concluídas.
- `historico/instalacao/` — instruções antigas dos pacotes incrementais.

Os arquivos históricos são mantidos para rastreabilidade, mas não fazem parte da execução do sistema.
