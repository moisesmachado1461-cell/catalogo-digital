FASE 23.1 — PERFIL E SEGURANÇA DO SUPER ADMIN

1. Copie o conteúdo deste pacote para a raiz do projeto.
2. No terminal:
   git status
   git add .
   git commit -m "Fase 23.1 - perfil e seguranca do super admin"
   git push

3. O Render deve executar a migration 013 no deploy.
4. Confirme:
   https://catalogo-digital-api.onrender.com/api/health

Esperado:
"version": "23.1.0"

5. Abra o Super Admin, pressione Ctrl+F5 e acesse:
   Perfil e segurança

Teste:
- alterar nome;
- alterar e-mail usando a senha atual;
- trocar a senha;
- encerrar outras sessões.

IMPORTANTE:
Ao trocar a senha, use a nova senha no próximo login.
